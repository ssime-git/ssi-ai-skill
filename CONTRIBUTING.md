# Contributing

Thanks for helping improve SSI.

1. Fork and create a branch (`feat/...`, `fix/...`, `docs/...`, `chore/...`).
2. Run `npm test` and `npm run validate` (Node 20+). Both must pass.
3. Open a PR using the template. Keep it focused and explain the why.
4. SSI never merges, closes Issues or deploys. Contributions must keep that guarantee.

Bugs and ideas: open an Issue using the templates.
